# YAL's Localization CSV Merger

It is primarily intended for
[cmnLoc](https://yellowafterlife.itch.io/gamemaker-cmn-loc),
but maybe you can use it for something else too.

## Building

First, install [Haxe](https://haxe.org). Then,

1. Open Terminal/Command Prompt/etc. in the repository's directory
2. `haxe build.hxml`

If all is well, `docs/script.js` will be updated
